How a problem moves through MathRSI

Parallel agents develop proofs. Cross-model reviewers challenge them. New evidence returns to the right stage and becomes reusable research memory.

  1. Problem
  2. Recognize the domain
  3. Load its plugin, or the shared base alone
  4. Adaptive stages

Research wikiread before each obligation · write lemmas, counterexamples and failures · reuse in the next step

Does this reduction make the original problem easier?Global progress checks · v4 maintenance on main

At planned checkpoints—or when new local results leave the same bottleneck untouched—two independent agents reassess the whole problem. One checks what remains even if the current work succeeds; the other compares alternative routes and the total cost of finishing.

The coordinator then changes the next task: connect a missing proof step, change the representation, switch routes, assemble a sufficient result, or continue within a concrete budget. Necessary complete calculations retain their completion plan.

    Quick start

    Launch the mathematics workbench with Git, Python 3.10+, pipx and a signed-in agent CLI.

    git clone --depth 1 https://github.com/lisresearchgroup/math-rsi.git
pipx install "git+https://github.com/wanshuiyin/SuperARIS.git"
mathrsi

    Choose your problem directory and the cloned math-rsi folder in the wizard. Next time, just run mathrsi.

    To work directly in the clone, enter /mathrsi-research (Claude Code) or $mathrsi-research (Codex), followed by your problem.
