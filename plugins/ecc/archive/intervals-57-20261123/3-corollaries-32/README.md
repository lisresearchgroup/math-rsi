## 依据

源头定理（按原文引用，没有重跑作者的分类计算）：

- **T1**：S. Bouyuklieva, I. Bouyukliev, Classification of Linear Codes by Extending Their Residuals, Mathematical Software – ICMS 2020, LNCS 12097, pp. 173–180, DOI 10.1007/978-3-030-52200-1_17，Proposition 2：“Binary linear [41,14,14] codes do not exist.”
- **T2**：S. Kurz, The [46,9,20]_2 code is unique, Advances in Mathematics of Communications 15(3) (2021) 415–422, DOI 10.3934/amc.2020074, arXiv:1906.02621v2，Lemma 3.4：“No [47,10,20]_2 code exists.”
- **T3**：S. Kurz, The [46,9,20]_2 code is unique, Advances in Mathematics of Communications 15(3) (2021) 415–422, DOI 10.3934/amc.2020074, arXiv:1906.02621v2，Theorem 3.7：“No [85,9,40]_2 code exists.”

三条定理排除的都是“距离恰为 d”的码；这三格在码表里的上界正好是 d，所以各得到上界 d−1（步骤 S1–S3）。

没有用到的东西：拜罗伊特大学的上界改进表，以及 MathRSI 的 `[43,10,≥17]` 不存在性定理。

## 规则

记 `U(n,k)` 为当前已知的 `[n,k]` 上界。码一律指一般二元线性码，允许零坐标和重复坐标。

- **穿孔**：`[n,k,≥t+1]` 码（t≥1）删去一个坐标。距离至少 2 保证映射是单射，得 `[n−1,k,≥t]`。故 `U(n,k) ≤ U(n−1,k)+1`。
- **缩短**：`[n,k,≥t]` 码（k≥2）取一个不恒为零的坐标，在该坐标为零的码字构成 k−1 维子码，删去该坐标得 `[n−1,k−1,≥t]`。故 `U(n,k) ≤ U(n−1,k−1)`。
- **奇偶扩展**：距离恰为奇数 d 的 `[n,k]` 码加一位总奇偶校验，得 `[n+1,k,d+1]`。若 `U(n,k)=d` 且 `U(n+1,k) ≤ d`，则 `U(n,k) ≤ d−1`。
- **残码**：距离恰为 d 的 `[n,k]` 码（k≥2），对一个重量 d 的码字，把其余码字限制到它的支撑之外，得 `[n−d,k−1,≥⌈d/2⌉]`。若 `U(n,k)=d` 且 `U(n−d,k−1) < ⌈d/2⌉`，则 `U(n,k) ≤ d−1`。
- **Y1**：设 `[n,k]` 码的距离恰为 d，对偶码的最小距离为 w。取一个重量 w 的对偶码字；生成矩阵在这 w 个坐标上的列任意 w−1 个线性无关、w 个线性相关，秩为 w−1。在这 w 个坐标上缩短得 `[n−w,k−w+1,≥d]`。对偶码是 `[n,n−k]` 码，所以 `w ≤ U(n,n−k)`。若 `U(n,k)=d`、`U(n,n−k) ≤ k`，且对每个 `1 ≤ w ≤ U(n,n−k)` 都有 `U(n−w,k−w+1) < d`，则 `U(n,k) ≤ d−1`。

后三条都是在 `U(n,k)=d` 的前提下排除“恰为 d”，距离更大的码已被 `U(n,k)=d` 排除。
