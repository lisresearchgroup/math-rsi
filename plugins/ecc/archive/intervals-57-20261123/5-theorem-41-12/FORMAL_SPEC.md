# ECC 研究规格：二元线性 [41,12] 码（公开区间 14–15；首选构造 [41,12,15]，或证明不存在）

spec 版本：v3（2026-10-19）。v1 为 new_case.py 通用骨架；v2 补全外部依赖与起点；v3 用已直接阅读的2006年原文 Lemma 4 替代未核实的码表书目作为上界 import 来源。原目标与验收条件不变，Goal active。

## 核心问题与成功条件

构造矩阵 $G\in\mathbb F_2^{12\times41}$，满足

$$\operatorname{rank}_{\mathbb F_2}(G)=12,\qquad
\forall u\in\mathbb F_2^{12}\setminus\{0\},\quad\operatorname{wt}(uG)\ge15.$$

$C=\{uG\}$ 是长度 41、维数 12 的二元线性码；最小距离为非零码字最小汉明重量。原始定义允许任意二元矩阵，不预设 QC、循环、自同构、种子邻域、固定 residual、非零列或互异列。声称距离恰为 $d$ 时另交重量为 $d$ 的非零消息/码字见证。

记 $E(t)$ 为"存在二元线性 [41,12,≥t] 码"。公开结果为 $E(14)$ 成立、$E(16)$ 不成立（后者为外部依赖，见下文），唯一开放值是 $t=15$。

## 可接受成果

区间宽度为 1，两种结局各自闭合区间：

| 方向 | 需要证明 | 推出 |
|---|---|---|
| 下界（首选） | 显式构造满足 $E(15)$ | $d_2(41,12)=15$（上界为 import）；奇偶扩展得偶 [42,12,16]，$d_2(42,12)=16$ |
| 上界 | $\neg E(15)$ | $d_2(41,12)=14$；等价地不存在偶 [42,12,16]，$d_2(42,12)=15$ |

局部无解、求解器 UNKNOWN、提高辅助指标和种子改进都不是替代完成条件。

## 构造验收

1. 保存实际 12×41 二元矩阵以及列/位序约定；可执行生成程序同时交付展开后的矩阵。
2. GF(2) 消元检查秩等于 12；遍历全部 4095 个非零消息，最小重量至少 15。
3. 保存完整重量谱、达到最小重量的消息与码字、命令和原始输出。满秩保证消息到码字的映射单射，故该枚举覆盖整个非零码。
4. 最终突破用独立实现复算；至少一条实现直接读取显式矩阵，不依赖搜索器的结构展开或缓存谱。probe-only 不能验收。
5. 声称提高公开下界时重新查询权威码表与相关原始文献；新颖性判断独立于构造合法性。

`verify_code`（`ecc_mathagent_harness_20260929/project/mathagent_ecc/verifier.py`）设置 `target_distance=15`、`exact_dimension_limit>=12`、`exact_after_probe_counterexample=True`、`collect_weight_distribution=True`。达标须同时满足 `n=41, field=2, declared_k=k=rank=12, status=verified, proof_level=exact, distance>=15`，核对 `exact_witness` 与非零重量谱总数 4095，并显式保存 `report.weight_distribution`（`to_dict()` 与默认证书不导出谱）。`MatrixSpec` 推导出的维数不能代替对期望维数 12 的检查。独立检查器的 `target_constructed=true` 和实际参数也是验收项；退出码 0 只说明脚本正常完成。不得沿用其他 case 的 k、消息数或距离设置。

## 不存在性验收

声称 $\neg E(15)$ 时，须覆盖全部满足秩 12、全部非零消息重量 ≥15 的 12×41 二元矩阵，不附加未经无损归约证明的结构限制。可交付严格数学证明，或经正确、完备编码及可靠检查器验证的完整证书；后者须分别闭合"保留的都合法"与"合法的没有漏掉"：归约、对象编码、分类覆盖、实际完整遍历、拒绝判定和输入绑定。外部不存在性结果须回到原文，记录定理、条件和实际阅读范围，并在结论中列为 import。完整证明经 proof-checker 正式审计，并由 MiniMax 与 Gemini 审阅。固定母码、固定 residual、对称子族或求解器超时只记录其实际覆盖范围。

## 可用等价形式与依赖

**奇偶扩展（无依赖）。** $E(15)$ ⟺ 存在偶 [42,12,≥16] 码。加总校验位使非零重量变为 ≥16 的偶数；反向穿孔任一位重量至多减 1，穿孔核只能含支撑在单坐标上的码字，距离 ≥16 排除之，维数仍为 12。使用偶 42 长表示时须实际穿孔导出 12×41 矩阵再按本规格验收。

**唯一核心 import：$\neg$[39,10,16]。** 已直接阅读 I. Bouyukliev, S. Bouyuklieva, T. Aaron Gulliver, P. R. Östergård, *Classification of optimal binary self-orthogonal codes*, J. Combin. Math. Combin. Comput. 59 (2006), 33–87，印刷 p.85 **Lemma 4**：“No linear [39,10,16] code exists.” 全文对象为二元线性码；引理的结论不是仅限自正交码。PDF：`ref/lemma4-jcmcc-2006.pdf`；实际阅读证据：PDF第53页/印刷85的 `work/20261019-import-lemma4/page-53.png` 与第55页/印刷87的 `page-55.png`。期刊公开下载来源及回执见该路线目录。

原文证明引用 Jaffe [14] 得假想码双偶且谱为 $1+367y^{16}+414y^{20}+240y^{24}+2y^{28}$，取重量28码字的 residual 得偶 [11,9,2]，继而声明四个无零坐标等价类均无法扩张为所需双偶码。[14] 实际是 Jaffe 的在线 *Information about binary linear codes*，不是先前猜测的1997年论文。本case**把 Lemma 4 整体作为外部 import**：已定位并阅读发表结论和证明段，未独立重放 Jaffe 约化及四类扩张的计算证书。Griesmer 对 [39,10,≥17] 要求长度≥41，故此引理足以排除 [39,10,≥16]。

码表仍标注 Boukliev 1994 四元维5 preprint；其历史引用与本结果的关系尚未查明，保留为书目问题，不再作为唯一数学来源。本 case 用到的其他相邻上界都由该外部引理经标准操作推出（缩短：$d_2(n-1,k-1)\ge d_2(n,k)$；奇偶扩展：奇 $d$ 的 [n,k,d] 给出 [n+1,k,d+1]）：

- $d_2(41,12)\le15$：[41,12,16] 缩短两次得 [39,10,16]。
- $d_2(38,10)\le14$：[38,10,15] 加校验位得 [39,10,16]。
- $d_2(40,12)\le14$：[40,12,15] 缩短两次得 [38,10,15]。
- $d_2(39,11)\le14$：[39,11,15] 缩短一次得 [38,10,15]。

$d_2(42,12)\le16$ 由 Griesmer 界直接给出（$d=17$ 需 $n\ge43$），不依赖 import。Griesmer 对 $[n,12,15]$ 只给 $n\ge37$，对 $[n,12,16]$ 只给 $n\ge38$，不足以单独回答本题。以上相邻上界均依赖已定位原文的外部 import；不标成本地独立证明。

**在 import 下的无损归约（研究 $E(15)$ 时可用，结论须列 import）：**

- *距离恰为 15。* 任何 [41,12,≥15] 码距离恰为 15，因此含重量 15 码字。
- *Projective。* 零列删除得 [40,12,≥15]，重复列缩短两位得 [39,11,≥15]，二者均违反上表；故目标的列是 PG(11,2) 中 41 个互异点。
- *Residual。* 对重量 15 码字换基为 15 个 $(1,a)$ 列与 26 个 $(0,b)$ 列，$a,b\in\mathbb F_2^{11}$。对每个非零 $s\in\mathbb F_2^{11}$，令 $p_s=|\{a:s\cdot a=1\}|$、$q_s=|\{b:s\cdot b=1\}|$，完整约束为
  $$p_s+q_s\ge15,\qquad 15-p_s+q_s\ge15\ (\text{即 } q_s\ge p_s),$$
  另加消息 $(1,0)$ 的重量 15；共 $2\times2047+1=4095$ 条。由此 $q_s\ge8$，residual 是 [26,11,≥8] 码；公开 $d_2(26,11)=8$（Griesmer 链），所以 residual 本身不排除目标，但必须是 [26,11,8] 码。
- *缩短链（必要条件）。* 目标缩短两次得 [39,10,≥15]，在 import 下即 [39,10,15]（已知存在）；缩短一次得 [40,11,≥15]（已知存在，$d_2(40,11)=15$）。若用"分类全部某类子码再扩展"证明不存在，须证明分类完整并覆盖全部扩展。

以上归约仅在 import 成立时无损；不使用 import 的路线（例如直接对偶 [42,12,16] 做线性规划/分类）可以不列该依赖。
