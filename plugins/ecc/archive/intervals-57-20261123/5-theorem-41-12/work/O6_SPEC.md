# O6 计算规格（主实现与独立实现共用的数学定义；2026-11-22，root 撰写）

本文件只给数学定义、标号约定和输出格式。实现方法由各实现自定；两套实现之间不得共享代码。

## 1. 输入

母码 K：F₂ 上的 κ×N 生成矩阵（每行一个 0/1 字符串，左起第 0 个字符是坐标 0）。要求行秩为 κ、每行偶重（故 K 是偶码）。记 ρ = N − κ（本题三类母码 ρ=29，小域测试 ρ 更小）。

参数：尾长 w ∈ {2,…,6}，目标距离 D（偶数）。本题 D=16；(N,κ,w) ∈ {(38,9,4),(37,8,5),(36,7,6)}。记头数 m = w−1。

## 2. 规范伴随式标号（两套实现必须一致，逐位定义）

1. 对 G 做 GF(2) 行化简到 **最左主元的简化行阶梯形 RREF**：主元列 p₀<p₁<…<p_{κ−1}，行 r_i 在 p_i 处为 1、在其它主元列为 0。RREF 由行空间唯一确定。
2. 自由坐标 Q = {0..N−1} \ {p_i}，升序 q₀<q₁<…<q_{ρ−1}。
3. 规范化映射 Nrm(x) = x + Σ_i x_{p_i}·r_i。它线性、保持陪集 x+K、像在主元坐标上全零，是该陪集唯一的“主元处为零”代表。
4. 向量 x 的伴随式是整数 s(x) = Σ_t Nrm(x)_{q_t}·2^t ∈ [0,2^ρ)。伴随式 s 的规范代表 x_s 只在 Q 上非零，x_s[q_t] = (s 的第 t 位)。s(x⊕y)=s(x)⊕s(y)。
5. depth(s) = min_{c∈K} wt(x_s + c)（陪集最小重量）。K 为偶码，故陪集内奇偶一致，奇偶性 = popcount(s) mod 2。

## 3. 集合与条件

阈值：τ(1)=τ(2)=D−2，τ(3)=τ(4)=D−4，τ(5)=D−6。

- F = { s : popcount(s) 偶, depth(s) ≥ D−2 }（s=0 的 depth 为 0，不在 F 中）。
- 一组头 {s₁<s₂<…<s_m} ⊂ [1,2^ρ)（无序集合，按整数升序记录）称为**解**，当且仅当对每个非空子集 T ⊆ {1..m}：
  popcount(⊕_{i∈T} s_i) 为偶，且 depth(⊕_{i∈T} s_i) ≥ τ(|T|)。
- 等价的分级统计量（都按无序集合计数）：
  - `F_size` = |F|
  - `edges` = #{ {a,b} ⊂ F, a≠b : a⊕b ∈ F }
  - `c3` = #{ 3 元集，全部 7 个非空子集条件成立 }
  - `c4` = #{ 4 元集，全部 15 个条件成立 }
  - `c5` = #{ 5 元集，全部 31 个条件成立 }
  只统计到 j ≤ m 的 c_j；`solutions` = c_m（m=3 时为 c3，m=4 为 c4，m=5 为 c5；m=1 为 F_size，m=2 为 edges）。

数学含义（证明在 PROOF 草稿，不由实现负责）：解 ⟺ 生成矩阵
```
[ K            | 0…0        ]   κ 行
[ x_{s_i}      | e_i + e_w  ]   i=1..m（尾部长 w，第 i 位与第 w 位为 1）
```
生成的 [N+w, κ+m] 码最小距离 ≥ D（前提：K 本身最小距离 ≥ D）。

## 4. 每个母码的输出（JSON，一个母码一个文件）

```
{"N":..,"kappa":..,"rho":..,"w":..,"D":..,
 "pivots":[p0,..],"free":[q0,..],
 "min_distance_K":..,                      // 全枚举 2^κ
 "F_size":..,
 "F_sha256":"..",                          // F 的全部元素按整数升序，每个写成十进制加 '\n'，对拼接字节串取 SHA-256；F 为空时是空串的 SHA-256
 "depth_hist_even":{"0":..,"2":..,...},    // 可选：偶伴随式按 depth 的个数（给得出就给）
 "edges":.., "c3":.., "c4":.., "c5":..,    // 只到 j≤m
 "solutions":..,
 "solution_list":[[s1,..,sm],...],         // 全部解（升序元组，按字典序）；超过 100000 个时只写前 100000 个并置 "solution_list_truncated":true
 "seconds":.., "impl":"..."}
```

## 5. 出现解时

对每个解（至少第一个）展开 §3 的 (κ+m)×(N+w) 矩阵，全枚举 2^{κ+m}−1 个非零码字，报告最小距离与重量谱；本题参数下再删去最后一个坐标得 12×41 矩阵并同样全枚举。把矩阵原样写入文件，立即向 root 报告，不要继续别的事。

## 6. 说明（2026-11-22，Grok 审阅后补充；不改变 §1–§5 的任何定义）

- §3 的“数学含义”一句准确的说法是：**偶伴随式组**满足全部深度条件 ⟺ 相应偶扩张的最小距离 ≥ D。偶性（popcount 偶）是解的定义的一部分；奇头的扩张即使距离达标也不计为解。否定方向只用到“偶 [42,12,≥16] 码给出一个解”，不用反向。
- `c3`、`c4`、`c5` 的论域是 F 的子集（两两异或也在 F 中），大小 ≥3 的子集和按 τ（depth ≥ D−4、D−6）检查，不是按 F 的成员资格检查。
