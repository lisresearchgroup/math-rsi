# verify_a：方法与完备性证明

接口：`verify_a G.txt D out.json [threads]`（`SPEC_HITS.md` 第 3 节）。判定 `d(C) ≥ D`，C 是 G 的行空间。精确、完整，无抽样、无概率步骤、无近似；
内存不够时报错退出（退出码 3），不降级。与 `src/layers3.c` 没有任何共用代码或数据结构。

## 1. 判据

设 G 为 K'×N（K' = 行数），rank(G)=k，ρ' = N − k。对 G 行化简（RREF，主元列集 P，|P|=k，其余列 F，|F|=ρ'），
得校验矩阵 H'（ρ'×N）：第 m 个自由列 f_m 对应一行，其上 H'[m][f_m]=1，H'[m][p_i]=RREF 第 i 行在 f_m 处的元素，其余为 0。
记 H' 的第 j 列为 h_j ∈ F₂^{ρ'}（程序里是 64 位整数，ρ' ≤ 62）。

**引理 0**：c ∈ F₂^N 属于行空间 ⟺ H'c = 0 = Σ_{j∈supp c} h_j = 0。
证明：C 的每个码字 c = Σ_i c[p_i]·R_i（R_i 为 RREF 第 i 行），在自由坐标 f_m 上 c[f_m] = Σ_i c[p_i]R_i[f_m]，即 H'c=0 的第 m 个方程；
反之满足这 ρ' 个方程的 c 由其主元坐标唯一确定，等于 Σ c[p_i]R_i。故 ker H' = C（维数都是 k）。∎
（程序另外自检：原始 G 的每一行都满足 Σ_{j∈supp} h_j = 0。）

**引理 1**：d(C) ≥ D ⟺ 不存在非空列集 S、|S| ≤ D−1、Σ_{j∈S} h_j = 0。
证明：支撑为 S 的码字存在 ⟺ Σ_S h_j = 0（引理 0），其重量为 |S|。∎（C={0} 时无非零码字，判真。）

记 m = D−1，a = ⌊m/2⌋ = ⌊(D−1)/2⌋。

**引理 2（折半）**：
- 若存在非空 S，|S|=w ≤ m，和为 0，则把 S 分成不交的 A、B，|A|=⌊w/2⌋、|B|=⌈w/2⌉，Σ_A = Σ_B。此时 |A| ≤ ⌊m/2⌋ = a，且 |B| ≤ ⌈m/2⌉。
- 反之，若 A≠B 是两个集合，和相等，则 S = A△B 非空、和为 0、|S| ≤ |A|+|B|。

**D 为奇数（m = 2a）**：判据为
(i) 所有大小 ≤ a 的列集，其和两两不同（把空集也算入，和为 0）。
- 若 (i) 不成立：有 A≠B、|A|,|B| ≤ a，和相等；S=A△B 非空（A≠B），|S| ≤ 2a = m，故 d ≤ |S| < D。
- 若 (i) 成立但 d < D：有非空 S、|S| ≤ 2a，由引理 2 分成不交的 A、B，|A|=⌊w/2⌋ ≤ a，|B|=⌈w/2⌉ ≤ a（w ≤ 2a），B 非空（w ≥ 1），A、B 不交，故 A≠B，和相等，与 (i) 矛盾。
所以 d ≥ D ⟺ (i)。

**D 为偶数（m = 2a+1）**：判据为 (i) 且
(ii) 没有大小恰为 a+1 的列集 B，其和等于某个大小 ≤ a 的列集 A 的和。
- 若 (i) 或 (ii) 不成立：(i) 不成立同上得 d ≤ 2a < D；(ii) 不成立时有 |B|=a+1，|A| ≤ a，和相等，|A|≠|B| 故 A≠B，S=A△B 非空，|S| ≤ 2a+1 = m，故 d < D。
- 若 (i)(ii) 都成立但 d < D：有非空 S，|S| = w ≤ 2a+1。w ≤ 2a 时同上由 (i) 矛盾；w = 2a+1 时分成不交的 A、B，|A|=a，|B|=a+1，和相等，与 (ii) 矛盾。
所以 d ≥ D ⟺ (i) 且 (ii)。

D = 1：m=0，无需任何检查，判真。D = 2：a=0，(i) 空；(ii) 即“没有和为 0（空集的和）的单列”，即没有零列。

## 2. 实现

- **阶段 (i)**：对 k=1..min(a,N)，枚举全部大小为 k 的列子集，把和写入 2^{ρ'} 位的位图（初始只有空集的和 0）。
  每次写入用原子 `fetch_or`，旧位为 1 即发现重复（精确：位图的一位对应一个和，不同子集和相同 ⟺ 同一位被写两次）。
- **阶段 (ii)**（D 偶数）：枚举全部大小为 a+1 的列子集，只读查位图，命中即违反 (ii)。这一步之前位图里恰是所有大小 ≤ a 的子集和。
- 并行：工作单元是前两个元素 (i1<i2)（k=1 时是单个元素），原子计数器领取；最后一层循环做软件预取（位图一般远大于缓存）。
  工作量计数与线程数无关（判真时）。判假时先到者先停，计数是提前终止时的数字。
- **见证**：命中给出一个子集 X 和它的和 v。再用同一枚举框架（`find` 模式）找一个 ≠X、和为 v、大小 ≤ a 的子集 Y
  （阶段 (i) 时 Y 因重复必然已存在；阶段 (ii) 时 Y 因命中必然存在）。见证码字 = 指示向量(X△Y)。程序自检：非零、重量 < D、H'c=0、
  c 属于 G 的行空间（用 RREF 把 c 约化到零；与引理 0 的 H' 判据是两个独立检查）。自检失败则退出码 5，不写结果。
- 输入检查：行数/行长一致，只含 0/1（容忍 CRLF 和末尾空行；行间空行、空文件、行长不一致、非 0/1 字符均退出码 2）。输出里的 `k` 是 G 的实际秩，`rows` 是行数。
- 内存：位图 2^{ρ'} 位 = 2^{ρ'−3} 字节（ρ'=38/39/40：32/64/128 GiB），用 `mmap` 匿名页并请求大页；
  先读 `/proc/meminfo` 的 MemAvailable 和 cgroup 限额，位图大于其 95% 时打印原因并以退出码 3 退出，不写 out.json。
  环境变量 `VERIFY_A_MAX_GIB` 可再设一个更小的上限。其余内存可忽略（线程缓冲、列整数数组 < 1 MiB）。
- 为什么 (i) 的枚举量不会超过位图：(i) 要求 Σ_{k≤a} C(N,k) 个和两两不同，若超过 2^{ρ'} 则必有重复，程序最多插入 2^{ρ'}+1 个就会发现并停止。

## 3. 规模估算（ρ' = 38–40，需上 Cluster，由调度者安排；此处未提交任何任务）

计数公式：阶段 (i) 插入 I = Σ_{k=1..a} C(N,k)；阶段 (ii)（D 偶数）探测 P = C(N, a+1)。内存 = 2^{ρ'−3} 字节。
